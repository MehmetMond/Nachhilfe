# Lagemaße üben

Interaktive Übungen zu den Lagemaßen aus Statistik 1: Modus, Median, Quantile, Boxplot,
arithmetisches, getrimmtes, geometrisches und harmonisches Mittel, lineare Transformation und Schiefe.
Mit geführter Lösung von Übungsblatt 3, Spielplatz für eigene Daten, Übungsgenerator, Karteikarten und Abschlussquiz.

Inoffizielle Lernhilfe. Die Rechenregeln folgen den Vorlesungsfolien (Quantile nach Folie 101, in R `type = 2`).

Der Lernfortschritt bleibt nur im eigenen Browser gespeichert (localStorage).
